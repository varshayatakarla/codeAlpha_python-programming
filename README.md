# codeAlpha_python-programming
This repository contains three Python projects completed as part of my CodeAlpha Python Programming Internship.

## About
This repository contains four Python projects completed as part of my Python Internship. These projects helped me improve my programming skills and gain practical experience.

## Projects

### 1. Hangman Game
A word-guessing game with difficulty levels, hints, scoring, and replay options.

**Concepts:** Random module, Lists, Dictionaries, Functions, Loops.

### 2. Stock Portfolio Tracker
Calculates stock investment values based on stock prices and quantities and saves the portfolio in a text file.

**Concepts:** Dictionaries, Functions, File Handling, Exception Handling.

### 3. Task Automation – File Organizer
Automatically organizes files into folders based on their extensions.

**Concepts:** OS, Shutil, File Handling, Loops, Dictionaries.

### 4. Basic Chatbot
A rule-based chatbot that responds to predefined user messages.

**Concepts:** Dictionaries, Functions, Loops, Conditional Statements, String Methods.
