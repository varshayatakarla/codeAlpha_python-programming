# codeAlpha_PythonProgramming

##  About the Project

This repository contains three Python projects developed as part of my Python Internship. These projects helped me gain practical knowledge of Python programming and understand how programming concepts can be used to solve real-world problems.

## Projects Included

### 1. Hangman Game
A fun word-guessing game where users try to guess a randomly selected hidden word.

**Features:**
- Three difficulty levels: Easy, Medium, and Hard.
- Random word selection.
- Hint option.
- Limited attempts and score calculation.
- Replay option.

**Concepts Used:** Random module, Lists, Dictionaries, Functions, Loops, and Conditional Statements.

### 2. Stock Portfolio Tracker
A Python program that calculates the total investment based on stock names, prices, and quantities.

**Features:**
- Displays available stocks and sample prices.
- Accepts stock names and quantities.
- Calculates individual investment values.
- Displays the total portfolio value.
- Saves portfolio details in a text file.

**Concepts Used:** Dictionaries, Lists, Functions, Loops, File Handling, and Exception Handling.

*Note: Stock prices are sample values and not live market prices.*

### 3. Task Automation – File Organizer
A Python automation program that organizes files into separate folders based on their file extensions.

**Features:**
- Identifies file extensions automatically.
- Creates folders for different file types.
- Organizes JPG, JPEG, PNG, PDF, and TXT files.
- Moves files into their respective folders.
- Skips duplicate files.

**Concepts Used:** OS Module, Shutil Module, File Handling, Dictionaries, Functions, and Exception Handling.

##  Technologies Used

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or Python IDLE.
3. Select the Python file you want to execute.
4. Run the program.

Example:

```bash
python Task1_Hangman.py
```

For Task 3, create a folder named `My_Files` and add sample files before running the program.
